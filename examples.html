EXAMPLES

Four complete pages built only from the component classes and tokens — no page-local CSS, no exceptions. View source on any of them; what you see is what you'd write.

  1. 01 LOGIN Sign-in and sign-up tabs, a toggle, and an honest error state — the form components in their natural habitat.
  2. 02 ARTICLE Kicker, byline, measure-width body, a pull quote, a figure, and footnotes — the editorial layout end to end.
  3. 03 DASHBOARD Sidebar navigation, stat blocks, tabs, a striped data table, a dropdown, and toasts — density without noise.
  4. 04 PRICING Three tiers with the middle one inverted, a comparison table, and an accordion FAQ — persuasion in grayscale.

Each example is a standalone file under examples/ — copy one as a starting point and delete what you don't need.
