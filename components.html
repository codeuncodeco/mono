09 — Table

Structure from the header rule, row shading, and breathing room. Add .table-striped for zebra rows or .table-dense for data-heavy views. Wrap wide tables in .table-scroll so phones scroll instead of crushing columns — cell padding grows on small screens, it never shrinks. For phone-first data, .table-stack turns each row into a labelled card under 640px (give every cell a data-label).

Perfect what remains: typography, spacing, and proportion.

Create patterns and relationships with limited elements.

11 — Accordion

Native <details> — zero JavaScript, fully keyboard accessible, and the browser remembers how it works.

Does it work without JavaScript?

Yes. This accordion is a native <details> element; the only thing CSS adds is the plus-minus marker.

Can more than one be open?

By default, yes. Add a shared name attribute to make them exclusive in modern browsers.

SHOW CODE 
<details class="accordion">
  <summary>Does it work without JavaScript?</summary>
  <p>Yes. It's a native element.</p>
</details>

12 — Modal

Native <dialog>: focus trapping, Escape, and the backdrop come free from the browser. Clicking outside closes it.

Delete everything?

This will remove all color from your project. Which, to be fair, is the whole idea.

SHOW CODE 
<button class="btn" data-mono-modal-open="confirm">Open modal</button>

<dialog id="confirm" class="modal" aria-labelledby="confirm-title">
  <h3 id="confirm-title" class="text-step-2 font-bold">Delete everything?</h3>
  <p>…</p>
  <button class="btn btn-secondary" data-mono-modal-close>Cancel</button>
  <button class="btn" data-mono-modal-close>Proceed</button>
</dialog>

14 — Tooltip

Pure CSS via data-tooltip; it appears on hover and on keyboard focus. Keep it to a few words — tooltips are captions, not paragraphs.

SHOW CODE 
<button class="btn btn-secondary"
        data-tooltip="Saves to local storage">Hover or focus me</button>

15 — Toast

Call mono.toast('message') from anywhere, or put the message in a data-mono-toast attribute. Toasts land in a role="status" region and dismiss themselves.

SHOW CODE 
<!-- Declarative -->
<button class="btn" data-mono-toast="Changes saved.">Save changes</button>

<!-- Programmatic -->
<script>
  mono.toast("Changes saved.");
</script>

16 — Surfaces & structure

Structure is a token, not a habit. .panel reads the structure axis: soft (the default) builds from shades and whitespace, lines boxes everything in ink, min dissolves into negative space. Switch it here — or in the TUNE panel — and the whole site follows. In dark mode the tiers become layered grays, never flat black.

applies live, saves to your browser

--paper

The page itself. Everything sits on it.

.panel

Cards, frames, tiers — one shade up (or one border out, in lines mode).

.panel-raised

A second step for emphasis and nested surfaces.

SHOW CODE 
<!-- The structure axis lives on <html> -->
<html data-structure="soft">   <!-- outlined | soft | minimal -->

<div class="panel p-6">A card.</div>
<div class="panel-raised p-6">A raised card.</div>
<div class="panel-inverse p-6">Solid ink.</div>

<script>
  monoTheme.set({ structure: "minimal" }); // applies + persists
</script>

17 — Tab bar & sheet

Phone navigation that behaves like an app: a fixed bottom bar with icons and thumb-sized targets, and a bottom sheet (<dialog class="sheet">) as the mega menu for everything beyond four destinations. This site uses it on every page — shrink the window and look down. The demo below is the same component, inline.

HOME SEARCH ALERTS

Everything else

Open MORE — the sheet slides up on phones and centers on desktop. Escape, backdrop, and ✕ all close it.

18 — Icons

One vocabulary, four libraries. Write <i class="icon" data-icon="settings"></i> once; Lucide, Tabler, Phosphor, or Material Symbols renders it — whichever is active. Switch sets here or in the TUNE panel; the choice persists and the whole site re-draws.

SHOW CODE 
<!-- One canonical name, any library -->
<i class="icon" data-icon="settings" aria-hidden="true"></i>
<i class="icon icon-sm" data-icon="search" aria-hidden="true"></i>
<i class="icon icon-lg" data-icon="home" aria-hidden="true"></i>

<script>
  monoTheme.set({ icons: "phosphor" }); // lucide | tabler | phosphor | material
</script>
